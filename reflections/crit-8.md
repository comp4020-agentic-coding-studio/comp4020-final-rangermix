# Crit 8 reflection

**What was the breakthrough that moved the work forward?**

The breakthrough this week was the agent checking my idea against the course's fixed setup before we designed anything. I wanted a cat café where the cats keep living when nobody is around, but the course's `fly.toml` stops the machine when nobody is connected. If I'd found that after building the simulation, I'd have had to rewrite it. Because the agent raised it in its first message, the answer, fast-forwarding the world when the server wakes, became part of the design from the start.

The second thing that helped was asking for questions in batches. With four or five at once I could see how the answers affected each other, like how carrying a cat ties into trust and into the cat's grudge when it gets angry, and I answered nineteen questions in about an hour and a half.

**What did this work change about who I want to be as a software developer?**

This is the most important week of the project. Everything that makes the café more than "a chat room with the nouns swapped" was decided in conversation: the cap of six, the line at the window, cats that set their own boundaries instead of house rules. The agent was good at finding problems and laying out options with their costs, but every choice that gave the café its character was mine. I want to be the developer who knows what the thing should feel like and can say it precisely enough that an agent can build it - albeit with some AI's help XD
